# 🛡️ Administration Centralisée & Sécurisation par GPO (Active Directory)

Ce projet documente la mise en place et le déploiement d'Objets de Stratégie de Groupe (**GPO**) dans un environnement **Windows Server avec Active Directory** pour sécuriser et standardiser les postes de travail et utilisateurs du domaine.

---

## 📌 Objectifs & Périphérie Technique
- **Administration Centralisée :** Configuration globale des politiques de sécurité pour l'ensemble des utilisateurs et machines du domaine AD.
- **Hardening Windows :** Application de restrictions d'accès, gestion des droits utilisateurs, sécurisation des sessions et déploiement de règles système.
- **Audit & Vérification :** Validation du déploiement des stratégies via les outils de diagnostic (`gpupdate /force`, `gpresult`).

---

## 🛠️ Environnement
- **OS Serveur :** Windows Server (Active Directory Domain Services - AD DS)
- **Outils d'Administration :** Console de gestion des stratégies de groupe (GPMC / `gpmc.msc`)
- **Clients :** Postes de travail Windows joints au domaine
